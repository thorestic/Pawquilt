# Pawquilt v0.1.0-preview

Transparent, nonactivating, topmost desktop companion with alpha hit testing, intentional body drag, head stroking, themed context menu and deterministic pause/exit controls. Physical monitor work areas, negative coordinates and per-monitor DPI guide movement.

Local weighted wandering, optional cursor approach, manual and automatic sleep, affection bubbles, break reminders, quiet mode and conservative fullscreen avoidance. Six additional supplied animation strips are connected to existing behaviors. Ordinary framed maximized windows no longer suppress visibility.

The user confirmed visible rendering and a happy jump on the current build. Code/model/render checks are documented in README; broader native interaction and hardware testing remains incomplete.
