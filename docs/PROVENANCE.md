# Pawquilt artwork and dependencies

Qa3moz is the original fox character supplied for Pawquilt: dark gray and cream fur, a green tail and facial accents, and a cyan pendant. The fox sprite material and previews were AI-generated with OpenAI tools at thorestic's request for this project. The owner authorized redistribution under CC BY 4.0 to the extent licensable. See [artwork notice](../assets/ARTWORK-NOTICE.md) and [art license](../assets/LICENSE) for scope, attribution and the full license.

Included artwork:

- The original 73-frame v2 atlas remains as a compatibility/fallback asset.
- Eleven approved pixel strips contain 37 frames.
- Six approved animation strips add 26 frames: light run, happy jump, somersault, ear scratch, sleepy stretch and request petting.
- The GIF and animation contact sheet show the supplied six-strip artwork. The menu preview is an offscreen render of the application's own controls.

Source-art pixels were copied without repainting or rescaling the files. Runtime rendering uses nearest-neighbor scaling. Timing from the supplied manifests was merged into a public runtime-only manifest; original private provenance, Library identifiers, local paths, generation sources and development reports were excluded. Unmodified originals remain in the private development workspace.

Application code was developed with ChatGPT/Codex assistance for the user's requested companion.
